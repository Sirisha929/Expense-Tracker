# Expense-Tracker
A simple and responsive Expense Tracker web application that helps users monitor their spending habits by logging income and expenses. Built with clean UI and real-time transaction updates, this project provides a straightforward way to track financial activities.


**🔧 Features**
✅ Add income and expense transactions

🗑️ Delete unwanted entries

📊 View current balance, total income, and total expenses

🧠 Automatically calculates summaries

💾 Stores data locally (can be extended with backend/database)

📱 Mobile-friendly responsive design




**🛠️ Technologies Used**


Language: C

File Handling: .txt file for persistent data storage

Compiler: GCC



**Steps**

1.Clone the repository
cd expense-tracker
2.Compile the program
3.Run the executable
